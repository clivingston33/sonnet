Most people want Sonnet. On a Mac with Apple silicon take the file whose name ends in arm64; on an Intel Mac take the other. On Linux take the .deb on Debian, Ubuntu and their relatives, and the .AppImage anywhere else.

The first time you open it

The apps are not code-signed, so the system asks before it runs them.

  • Windows: on “Windows protected your PC”, choose More info, then Run anyway.
  • macOS: open the app once, then go to System Settings → Privacy & Security and choose Open Anyway. If macOS says the app is damaged, run xattr -cr /Applications/Sonnet.app in Terminal and open it again.
  • Linux: make the AppImage runnable first: chmod +x Sonnet-*.AppImage. If it stops with a message about the sandbox, install the .deb instead, or start it with --no-sandbox.

Phones and tablets

There is nothing to download. Open your server in the browser and choose Add to Home Screen. See Other devices.

Run a server

On a home server or NAS, with Docker:

docker run -d --name sonnet --restart unless-stopped -p 3000:3000 \
  -v ./data:/data -v ./library:/library ghcr.io/clivingston33/sonnet

Then open http://localhost:3000. The docs cover folders, other devices and backups, and running it with Node instead.
